# 📊 APAスタイル 統計解析 Webアプリケーション (stats)

CSVファイルをアップロードしてデータ前処理（Recodeや特定値の除外など）を行い、目的の統計分析（基本統計量・検定・回帰・因子分析など）を選択して「分析を実行」ボタンを押すと、**APAスタイル（第7版）の表と図を統合した日本語Excelファイル (.xlsx)** を作成・ダウンロードできるWebアプリです。

---

## 🛠 機能一覧

### 1. データ前処理・加工ツール
- **特定値の除外**: 無効値（例: `-99`, `99` 等）を指定して除外
- **値のリコード (置換)**: 変数の値を任意の値に置き換えて新変数を作成
- **ビン分割 (カテゴリ化)**: 連続数値を指定の区切り値でカテゴリ変数に変換
- **合成スコア作成**: 複数項目から平均値または合計値の新変数を作成
- **逆転項目の反転リコード**: アンケートの逆転項目（$Y = (\min + \max) - X$）を一括反転
- **標準化・正規化**: Zスコア化（平均0・分散1）および 0-1 Min-Max 正規化
- **欠損値処理**: リストワイズ削除、平均値・中央値・最頻値・定数による補完
- **複数条件フィルタ**: AND/OR条件を組み合わせた柔軟なデータ抽出
- **ダミー変数化**: 名義尺度変数のOne-Hot Encoding（参照カテゴリ除外対応）

### 2. 統計分析メニュー (全12手法)
1. **単純集計 (度数分布)**: 頻度、割合、累積割合、度数分布棒グラフ
2. **基本統計量**: 平均、標準偏差、中央値、IQR、歪度、尖度、ヒストグラム＆KDE
3. **クロス集計 & カイ二乗検定**: 度数 (列%)、カイ二乗検定、クラメールのV、100%積層棒グラフ
4. **独立2群のt検定 / Welch検定**: Student / Welch、Cohen's $d$、平均値95%CI棒グラフ
5. **対応のあるt検定**: 同一被験者/対応2群の比較、差の平均、Cohen's $d_z$、前後比較プロット
6. **一元配置分散分析 (ANOVA)**: 主効果検定、効果量 $\eta^2$、Tukey HSD多重比較
7. **二元配置分散分析 (Two-Way ANOVA)**: 2要因の主効果・交互作用検定、部分 $\eta_p^2$、セル別統計量、交互作用プロット
8. **相関分析**: ピアソン / スピアマン相関係数、有意確率、相関行列ヒートマップ
9. **重回帰分析**: OLS回帰、標準化偏回帰係数 ($\beta$)、VIF（多重共線性診断）、実測 vs 予測プロット
10. **二項ロジスティック回帰分析**: オッズ比 (OR)、95%CI、Wald検定、疑似 $R^2$、フォレストプロット
11. **探索的因子分析 (EFA)**: 因子負荷量、Promax/Varimax回転、寄与率、固有値スクリープロット
12. **尺度信頼性分析**: クロンバックの $\alpha$ 係数、項目-全体相関、項目削除時 $\alpha$ プロット

## 📁 フォルダ構成

本アプリケーションは `stats` フォルダー内に格納されています。

- `stats/app.py`: メイン画面・Streamlit UI・前処理ツール・オンデマンド分析実行
- `stats/stats_engine.py`: 統計計算・データ編集（前処理各種）・APAグラフ生成エンジン
- `stats/apa_excel.py`: APA7thスタイル（日本語対応・罫線・注釈・画像/チャート埋め込み）Excelレポート作成機能
- `stats/requirements.txt`: 依存ライブラリ定義ファイル
- `stats/README.md`: 説明ドキュメント

## 🚀 アプリの起動手順

### 1. ディレクトリの移動
ターミナルで `stats` サブフォルダーに移動します。

```bash
cd stats
```

### 2. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 3. アプリの実行
```bash
streamlit run app.py
```

ブラウザが立ち上がり、 `http://localhost:8501` でアプリをご利用いただけます。
